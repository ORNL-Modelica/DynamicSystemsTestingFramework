# The Cut Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The report page stops computing anything. Every number it draws comes from an embedded figure dict or a server-rendered string; the JavaScript scorers, editors, tree builder and patch export are deleted with the Python that existed only to feed them, and the tests and documents that described them go or change shape. Decision D125 records that the two-tier split supersedes D66's boundary.

**Architecture:** Sub-project 2 of `docs/superpowers/specs/2026-09-08-two-tier-architecture-design.md` (§4.1, §4.4, §5 step 2, §6 "The report", §7). Sub-project 1 (`2026-09-08-geometry-and-figures.md`, shipped at aefdfdc) made the page's first paint come from Python figure dicts while the JS kept re-rendering on edit. This plan removes the edit path. The end state is §4.4's predicate: **no JavaScript under `templates/` computes a verdict, a bound, a box, a spectrum or an event; every number the page draws comes from an embedded figure dict or a server-rendered string.**

**Tech Stack:** Python 3.10+, Jinja2, the vendored plotly.js, pytest, Playwright (installed in this venv with Chromium; browser tests run for real).

**Revision:** this is the second text. A fresh-context review of the first found three intermediate commits red (the JavaScript, the Python that fed it, and the tests that assert either cannot be deleted in separate commits) and an order-dependent sentinel fix; Tasks 4 and 5 are therefore ONE task, and the other findings are folded in where they belong.

## Conventions for every task

- Run commands from the repo root with `uv run ...`. Gates before every commit: `uv run ruff check`, `uv run ruff format --check` (fix with `uv run ruff format <files>`), `uv run mypy` **bare, no path**, and the tests each task names. `uv run pytest -m playwright -q` is the browser suite; it runs, it does not skip. Every task's gate includes **both** `-m "not playwright"` and `-m playwright` runs — a task that deletes a Python symbol must not leave a browser test file importing it.
- **Commit with explicit paths — `git commit -F <msgfile> -- <paths>` — never a bare `git commit`.** Other agents may hold staged changes in the same index (DSTF-024 #1). New files need `git add <file>` first, then the path-scoped commit. Messages end with the attribution trailer the session's instructions specify. Nothing is pushed.
- **Never run `dstf compare` or `dstf run` against `testing_output/` or any real work directory** from a task or a review; `cmd_compare` wipes the report pages there at start (DSTF-024 #2). Tests use `tmp_path`.
- Done-checks are predicates over the end state, never counts.
- `docs/ideas.md` and `.soul/` are NOT touched by this plan. `docs/decisions.md` gains exactly one entry, D125, in Task 8.
- Calls made here, not in the spec: (1) the dashboard's command menu gains the commands that exist today (`run`, `compare`, `compare --accept`, `run --rerun failed,sim-failed`); the `dstf author ...` entry the spec lists waits for sub-project 4, when the command exists — a menu must not offer a command that fails. (2) The page carries **no trajectory arrays** after the cut: the surviving JavaScript reads only the figure dicts, so the page's copy of the context drops `variables_by_name[*].trajectory`, the overlay arrays, `diag_trajectories` and `nobaseline_trajectories` AFTER the sidecar is written and the figures are built; **`comparison_data.json` keeps exactly its current shape** (it is the documented downstream artifact). The decimation banner is server-rendered from the figures' `full_samples` stamps and `_decimate_context_for_html` goes. (3) The served file keeps its name, `interactive.js`; only the source part becomes `report.js`.
- The order below keeps the suite green at every commit: the kept-list assertions land FIRST on the current page, so the deletion commit is checked against them.

### Task 2: Sentinel leaves keep their variable's name, and the plot keeps its data

The figure layer pairs leaves with plots by variable name; the evaluator's sentinels decorated the name with the reason, so a misconfigured or baseline-less leaf never joined its plot. With the JavaScript fallback gone there is no second chance. A second trap sits beside it: sentinels carry `index=0`, `_build_trajectories` (`context_builder.py:557-573`) pairs trajectories by `vc.index`, and `variables_by_name` takes the FIRST trajectory with a matching name (`:926-934`) — so once the names match, a sentinel listed before the healthy leaf yields an EMPTY trajectory for the variable and a blank plot. Both are fixed here, and the test asserts both leaf orders.
