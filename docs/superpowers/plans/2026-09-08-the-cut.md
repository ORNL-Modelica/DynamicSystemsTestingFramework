# The Cut Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The report page stops computing anything. Every number it draws comes from an embedded figure dict or a server-rendered string; the JavaScript scorers, editors, tree builder and patch export are deleted with the Python that existed only to feed them, and the tests and documents that described them go or change shape. Decision D125 records that the two-tier split supersedes D66's boundary.

**Architecture:** Sub-project 2 of `docs/superpowers/specs/2026-09-08-two-tier-architecture-design.md` (§4.1, §4.4, §5 step 2, §6 "The report", §7). Sub-project 1 (`2026-09-08-geometry-and-figures.md`, shipped at aefdfdc) made the page's first paint come from Python figure dicts while the JS kept re-rendering on edit. This plan removes the edit path. The end state is §4.4's predicate: **no JavaScript under `templates/` computes a verdict, a bound, a box, a spectrum or an event; every number the page draws comes from an embedded figure dict or a server-rendered string.**

**Tech Stack:** Python 3.10+, Jinja2, the vendored plotly.js, pytest, Playwright (installed in this venv with Chromium; browser tests run for real).

## Conventions for every task

- Run commands from the repo root with `uv run ...`. Gates before every commit: `uv run ruff check`, `uv run ruff format --check` (fix with `uv run ruff format <files>`), `uv run mypy` **bare, no path**, and the tests each task names. `uv run pytest -m playwright -q` is the browser suite; it runs, it does not skip.
- **Commit with explicit paths — `git commit -F <msgfile> -- <paths>` — never a bare `git commit`.** Other agents may hold staged changes in the same index (DSTF-024 #1). Messages end with the attribution trailer the session's instructions specify. Nothing is pushed.
- **Never run `dstf compare` or `dstf run` against `testing_output/` or any real work directory** from a task or a review; `cmd_compare` wipes the report pages there at start (DSTF-024 #2). Tests use `tmp_path`.
- Done-checks are predicates over the end state, never counts.
- `docs/ideas.md` and `.soul/` are NOT touched by this plan. `docs/decisions.md` gains exactly one entry, D125, in Task 9.
- Two calls made here, not in the spec: (1) the dashboard's command menu gains the commands that exist today (`run`, `compare`, `compare --accept`, `--rerun`); the `dstf author ...` entry the spec lists waits for sub-project 4, when the command exists — a menu must not offer a command that fails. (2) The page carries **no trajectory arrays** after the cut: the surviving JavaScript reads only the figure dicts, so `variables_by_name[*].trajectory`, `diag_trajectories` and `nobaseline_trajectories` leave `window.MT_REPORT` and the decimation banner is server-rendered from the figures' `full_samples` stamps. `_decimate_context_for_html` goes with them; the sidecar `comparison_data.json` keeps its full-resolution shape because it is written before the figures are built.
- The order below keeps the suite green at every commit: the kept-list assertions land FIRST on the current page, so the deletion commits are checked against them.
