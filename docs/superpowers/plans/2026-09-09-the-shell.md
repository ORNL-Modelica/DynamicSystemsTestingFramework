# The Shell Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `dstf author --config testing.json` opens a browser tab on a NiceGUI shell over the Session: a test list, the centre figure with the read-only metric tree, one tab per applicable capability, a job panel, and the project-less state — plus the two v1 capabilities, Edit criteria and Edit tree, the form emitter they share, and the conformance test that proves a capability the shell has never heard of attaches.

**Architecture:** Sub-project 4 of `docs/superpowers/specs/2026-09-08-two-tier-architecture-design.md` (§4.6 as amended, §4.7, §4.8, §5 step 4, §6 "The tool", §7.2). Sub-project 3 shipped the Session (`src/dstf/authoring/session.py`), the capability contract (`capabilities.py`) and the spec document. This plan adds the UI layer beside them: `authoring/app.py` (the shell), `authoring/forms.py` (NiceGUI from `derive_schema`), `authoring/builtin/` (the two capabilities), and the `dstf author` command. The shell is fixed and knows no capability by name; it reads a `SessionView`, lists capabilities by scope, and routes every outcome through `Session.apply`. Nothing here touches simulation (the job panel shows a running job's label; the run callable is sub-project 5).

**Tech Stack:** Python 3.10+, NiceGUI 3.16 (the `[author]` extra), pytest-asyncio for NiceGUI's in-process `user_simulation` (no browser), Playwright + Chromium for the one smoke test, uv.

**Revision:** this is the second text. A fresh-context review against NiceGUI 3.16 found nine defects that would each have failed a whole task's tests as typed (top-level layout elements inside a refreshable; finds with no await after a refresh; a fixture importing a package a later task creates; the header showing the config dir's name; a substring the install hint does not contain; a label the schema does not produce; a `replace` on a path that does not exist yet) and three spec items with no task (the pending drawer, the inline leaf error, artifacts as links). All folded in; calls 8–10 below are new.

**Spike results this plan rests on** (run 2026-09-09 against NiceGUI 3.16.0 in a scratch venv, plotly.py NOT installed): `ui.plotly(<dict>)` renders a figure dict — the element guards its `plotly` import and passes a dict straight through, so §4.8's question is answered before Task 1 and Task 1 only pins it with a test. `nicegui.testing.user_simulation.user_simulation(root=<page function>)` yields a `User` that drives a page built by that function with no server and no browser: `await user.open("/")`, `user.find("<text>").click()`, `user.find(marker="m").type("5")`, `await user.should_see("<text>")`, `user.find(ui.plotly).elements`. Pages registered with `@ui.page` at import are wiped by the simulation's global reset, so the shell exposes a ROOT FUNCTION and `ui.run(root, ...)` mounts it. A `ui.timer(0.05, drain)` on the page runs under the simulation and is the bridge from a worker thread: the thread posts a callable to a `queue.Queue`, the timer drains it inside the page's context. `ui.tree`'s server-side `select()` does not fire `on_select`, so the read-only tree is rows of `ui.button`s, which `user.find(text).click()` drives.

Gates before every commit: `uv run ruff check`, `uv run ruff format --check` (fix with `uv run ruff format <files>`), `uv run mypy` **bare, no path**, `uv run pytest -q -m "not playwright"`, and the tests each task names. - **Commit with explicit paths — `git commit -F <msgfile> -- <paths>` — never a bare `git commit`.** New files need `git add <file>` first. Messages end with the attribution trailer the session's instructions specify. Nothing is pushed.
- **Never run `dstf run` / `dstf compare` / `dstf author` against `testing_output/` or any real work directory** from a task or a review; Task 12's real-library gate is the orchestrator's. Tests use `tmp_path`.
- Done-checks are predicates over the end state, never counts.
- `docs/ideas.md` and `.soul/` are NOT touched by this plan. `docs/decisions.md` gains no entry (D125 announced the tool; D126 the tree rule).
- **Every file under `src/dstf/authoring/` other than `app.py`, `forms.py` and `builtin/*` still imports no UI framework** (Task 12 predicate 1): the Session, the contract and the spec document stay pure.
- Calls made here, not in the spec (recorded in the spec's §4.6 note by Task 11):
  1. **`Panel` gains `submit(**inputs)`.** A capability builds its controls in the panel; when one fires, the capability calls `panel.submit(...)`, and the SHELL calls `act(view, **inputs)` and `Session.apply` on what comes back, showing an exception in the tab and leaving the Session unchanged. The spec defined `panel`/`act` but not who calls `act`.
  2. **`SessionView.tree_view(model_id)` and `SessionView.tree(model_id)`.** The read-only tree the shell shows (the report's own view dict, built by the same function) and the raw tree a Patch edits (the entry's `metrics`, or the tree `rescore` would materialize). Both read-only; both on the Session too.
  3. **`derive_schema` moves to `src/dstf/comparison/mode_schema.py`**; `reporting/ui/` is deleted. After the cut nothing in reporting renders a form; the two consumers are `export-schema` and this plan's form emitter.
  4. **The dashboard is served by the shell**, at `/dashboard/dashboard.html` (a static mount of the work dir), because a browser refuses a `file://` link from an `http://` page.
  5. **`--no-browser`** on `dstf author` (headless launch for the smoke test and the real-library gate). Default opens the tab, as §4.7 says.
  6. **Edit criteria stages on every control change** (§4.7: "each change stages one patch op"), as one `replace` of the whole leaf, so the pending drawer reads "leaf → new leaf" rather than a keystroke log. Edit tree stages one op per structural action.
  7. **Export writes `<work_dir>/spec_patch.json`** (the multi-model envelope) and shows the path; §4.7 says "writes an envelope" without saying where.
  8. **Consecutive `replace`s of one path collapse into one pending op** (`Session.stage`): Edit criteria stages on every control change, and without this the pending drawer and the exported envelope would be a keystroke log. The Session does it, so every capability gets it.
  9. **The shell serves on 127.0.0.1** (§4.7 "on localhost"); NiceGUI's default is every interface, and this process can write the spec and the store.
  10. **`tube_points` editing is sub-project 6's** (on-plot editing); this plan shows it read-only, as §4.7 says, and the "split upper / lower form" waits for the plot handles it belongs with.

```python
"""NiceGUI controls from a mode's Config dataclass (§4.7 "Edit criteria").

``derive_schema`` describes the dataclass — field name, type, default,
choices, label, help, bounds; this module turns each ``FieldSpec`` into one
control and hands the caller the live values. The NiceGUI emitter is the
sibling of ``reporting/schema_export``'s JSON-Schema emitter: same input,
different surface.
"""

from __future__ import annotations

import json
from collections.abc import Callable
from dataclasses import dataclass, field

from nicegui import ui

from ..comparison.mode_schema import FieldSpec, Schema

OnChange = Callable[[dict], None]


@dataclass
class Form:
    """The rendered controls, by field name, and their current values."""

    controls: dict[str, ui.element] = field(default_factory=dict)
    _values: dict = field(default_factory=dict)
    _passthrough: dict = field(default_factory=dict)

    def values(self) -> dict:
        """Every field the caller gave a value or the user edited — ``None``
        is "unset" and is omitted; a dataclass default is shown as the
        control's placeholder and never written (the evaluator falls back
        to the test's base tolerance for a leaf without one, and a written
        1e-4 would change that verdict). Passthrough fields keep the value
        they were given."""
        out = {k: v for k, v in self._values.items() if v is not None}
        out.update({k: v for k, v in self._passthrough.items() if v is not None})
        return out


def render_form(schema: Schema, values: dict, on_change: OnChange) -> Form:
    """Build one control per field into the current NiceGUI container.

    ``values`` pre-fills (missing keys fall back to the field's default);
    ``on_change`` receives the full values dict after every edit.
    """
    form = Form()
    for spec in schema.fields:
        current = values.get(spec.name)  # the default is a placeholder, not a value
        if spec.type == "passthrough":
            # Structured data (tube control points, declared peaks,
            # checkpoints): shown as JSON, read-only — on-plot editing (§5
            # step 6) is where these get their controls.
            form._passthrough[spec.name] = current
            form.controls[spec.name] = (
                ui.textarea(label=spec.label or spec.name,
                            value=json.dumps(current) if current is not None else "")
                .props("readonly outlined dense")
                .tooltip(spec.help or "edited on the plot, not here")
            )
            continue
        if spec.name in values:
            form._values[spec.name] = current
        control = _control(spec, current, lambda v, name=spec.name: _set(form, name, v, on_change))
        if current is None and spec.default is not None:
            control.props(f'placeholder="{spec.default}"')
        if spec.help:
            control.tooltip(spec.help)
        form.controls[spec.name] = control
    return form


def _set(form: Form, name: str, value, on_change: OnChange) -> None:
    form._values[name] = value
    on_change(form.values())


def _control(spec: FieldSpec, current, set_value: Callable) -> ui.element:
    label = spec.label or spec.name
    if spec.type in ("float", "int"):
        kwargs = {}
        if spec.ui_min is not None:
            kwargs["min"] = spec.ui_min
        if spec.ui_max is not None:
            kwargs["max"] = spec.ui_max
        if spec.type == "int":
            kwargs["step"] = 1
        return ui.number(label=label, value=current, on_change=lambda e: set_value(e.value), **kwargs).props("dense")
    if spec.type == "bool":
        return ui.checkbox(label, value=bool(current), on_change=lambda e: set_value(e.value))
    if spec.type == "enum":
        return ui.select(list(spec.choices or []), label=label, value=current,
                         on_change=lambda e: set_value(e.value)).props("dense")
    return ui.input(label=label, value="" if current is None else str(current),
                    on_change=lambda e: set_value(e.value)).props("dense")
```

(A `ui.number` whose value the user clears yields `None` → the field is unset, which is what "omitted" means. """The authoring shell (§4.6 "The shell", §4.7): fixed, and it knows no
```python
capability by name. It reads a SessionView, lists capabilities by scope,
and routes every outcome through Session.apply. Everything it draws comes
from the Session: the figure dict, the report's tree view, the verdicts."""

from __future__ import annotations

import json
import queue
from collections.abc import Callable
from pathlib import Path
from typing import Any

from fastapi.responses import FileResponse
from nicegui import app, ui

from ..cli.common import _filter_tests
from ..reporting.status import classify_with_class
from .capabilities import Capability, Scope, registered_capabilities
from .session import (
    JobRunningError,
    PendingEditsError,

class FigureHook:
    """`panel.figure.on(kind, handler)`: handlers get the primitive id and
    the Plotly event payload. Wired to the centre plot's Plotly events;
    no v1 capability subscribes (on-plot editing, §5 step 6, is the first)."""

    def __init__(self) -> None:
        self._handlers: dict[str, list[Callable[[str, dict], None]]] = {}

    def on(self, kind: str, handler: Callable[[str, dict], None]) -> None:
        self._handlers.setdefault(kind, []).append(handler)

    def attach(self, plot: ui.plotly) -> None:
        for event in ("plotly_click", "plotly_relayout", "plotly_selected"):
            plot.on(event, lambda e, kind=event: self._dispatch(kind, e.args))

    def _dispatch(self, kind: str, payload: Any) -> None:
        data = payload if isinstance(payload, dict) else {}
        points = data.get("points") or [{}]
        first = points[0] if isinstance(points[0], dict) else {}
        primitive = first.get("customdata")
        if primitive is None:
            primitive = first.get("curveNumber")
        for handler in self._handlers.get(kind, []):
            handler("" if primitive is None else str(primitive), data)


class ShellPanel:
    """The container a capability owns (§4.6 "Panel"): the current NiceGUI
    slot, the figure hook, and `submit` — the one way an outcome reaches
    the Session (Convention 1)."""

    def __init__(self, shell: Shell, cap: Capability, figure: FigureHook):
        self._shell, self._cap, self.figure = shell, cap, figure

    def submit(self, **inputs: Any) -> None:
        self._shell.act(self._cap, **inputs)


class Shell:
    """One per process. `root` builds the page; every region is a
    refreshable method the Session's events refresh."""

    def __init__(self, *, filter: str | None = None, package: str | None = None) -> None:
        self._posted: queue.Queue[Callable[[], None]] = queue.Queue()
        self.session = Session(post=self._posted.put)
        self.view = SessionView(self.session)
        self.filter, self.package = filter, package
        self.errors: dict[str, str] = {}  # capability name -> last error shown in its tab
        self.figure_hook = FigureHook()
        self._built = False
        # Session events -> regions. `tabs` is NOT on spec/results: Edit
        # criteria stages on every control change, and rebuilding the tab
        # would destroy the control being typed in. Tabs follow the
        # selection, the job (the lock reason), and an act error.
        self.session.on("spec", lambda e: self._refresh("header", "tests", "centre", "drawer"))
        self.session.on("results", lambda e: self._refresh("tests", "centre"))
        self.session.on("job", lambda e: self._refresh("jobs", "tests", "tabs"))
        self.session.on("selection", lambda e: self._refresh("tests", "centre", "tabs"))

    # -- lifecycle ---------------------------------------------------------

    def open(self, config_path: Path, *, backend: str | None = None, work_dir: Path | None = None) -> None:
        self.session.open(config_path, backend=backend, work_dir=work_dir)

    def visible_tests(self) -> list[str]:
        project = self.session.project
        if project is None:
            return []
        tests = _filter_tests(project.tests, self.filter, self.package)
        return [t.model_id for t in tests]

    def _refresh(self, *regions: str) -> None:
        """Refresh regions that exist. NiceGUI defers each refresh to a
        background task; before the page is built there is nothing to do."""
        if not self._built:
            return
        for region in regions:
            getattr(self, f"_{region}").refresh()

    # -- capabilities --------------------------------------------------------

    def applicable(self) -> list[tuple[Capability, bool | str]]:
        """Every registered capability whose scope matches the selection,
        with `available`'s answer. PROJECT always matches; TESTS needs a
        selection; VARIABLE a variable; LEAF a leaf. With no project open,
        only PROJECT-scope capabilities are listed (§4.6)."""
        sel = self.session.selection
        out = []
        for cap in registered_capabilities():
            if self.session.project is None:
                matches = cap.scope is Scope.PROJECT
            else:
                matches = (
                    cap.scope is Scope.PROJECT
                    or (cap.scope is Scope.TESTS and bool(sel.tests))
                    or (cap.scope is Scope.VARIABLE and sel.variable is not None)
                    or (cap.scope is Scope.LEAF and sel.leaf_path is not None)
                )
            if matches:
                out.append((cap, cap.available(self.view)))
        return out

    def act(self, cap: Capability, **inputs: Any) -> None:
        """`Panel.submit` lands here: the capability's `act`, then the
        Session applies the outcome. An exception is shown in the tab and
        the Session is what it was."""
        try:
            outcome = cap.act(self.view, **inputs)
            self.session.apply(outcome)
            if self.errors.pop(cap.name, None) is not None:
                self._refresh("tabs")
        except Exception as e:  # shown in the tab, never raised into NiceGUI
            self.errors[cap.name] = f"{type(e).__name__}: {e}"
            self._refresh("tabs")

    # -- the page ------------------------------------------------------------

    def root(self) -> None:
        """The index page. `ui.run(shell.root, ...)` mounts it; the tests
        mount it through `user_simulation(root=shell.root)`. Top-level
        layout elements (header, footer, drawer) are created here, once;
        only their CONTENT is refreshable."""
        self._add_routes()
        with ui.header().classes("items-center"):
            self._header()
        with ui.right_drawer(value=False) as self._drawer_el:
            self._drawer()
        with ui.row().classes("w-full no-wrap"):
            with ui.column().classes("w-1/5"):
                self._tests()
            with ui.column().classes("w-3/5"):
                self._centre()
            with ui.column().classes("w-1/5"):
                self._tabs()
        with ui.footer():
            self._jobs()
        ui.timer(0.1, self._tick)
        self._built = True

    def _add_routes(self) -> None:
        """The dashboard link (Convention 4): one route resolving the OPEN
        project's work dir per request, so an OpenProject swap follows."""
        if getattr(self, "_routes_added", False):
            return
        self._routes_added = True

        @app.get("/dashboard/{path:path}")
        def _dashboard(path: str):
            project = self.session.project
            if project is None:
                return {"error": "no project open"}
            target = (project.config.work_dir / path).resolve()
            if project.config.work_dir.resolve() not in target.parents or not target.is_file():
                return {"error": "not found"}
            return FileResponse(target)

    def _tick(self) -> None:
        """Drain what worker threads posted (a job's completion); the
        Session events it emits refresh the regions."""
        while True:
            try:
                fn = self._posted.get_nowait()
            except queue.Empty:
                return
            fn()

    @ui.refreshable_method
    def _header(self) -> None:
        project = self.session.project
        if project is None:
            ui.label("dstf — no project open")
            return
        cfg = project.config
        ui.label(cfg.library_name or "").classes("text-lg").mark("project")
        ui.label(f"backend: {cfg.backend_name}")
        ui.button(f"{len(self.session.spec.pending)} pending",
                  on_click=lambda: self._drawer_el.toggle()).props("flat").mark("pending")
        ui.button("Save", on_click=self._save)
        ui.button("Discard", on_click=self.session.discard)
        ui.button("Export", on_click=self._export)
        ui.link("dashboard", "/dashboard/dashboard.html", new_tab=True)
        ui.button("Close project", on_click=self._close)
        ui.button("Quit", on_click=app.shutdown)

    @ui.refreshable_method
    def _drawer(self) -> None:
        """The pending-patch drawer (§4.7): staged ops in readable form,
        grouped by model."""
        groups = self.session.spec.grouped()
        if not groups:
            ui.label("nothing staged")
            return
        for model_id, ops in groups:
            ui.label(model_id).classes("text-bold")
            for op in ops:
                value = json.dumps(op.get("value")) if "value" in op else ""
                ui.label(f"{op['op']} {op['path']} {value}"[:200]).classes("text-xs")

    def _save(self) -> None:

            self.session.save()
            ui.notify("saved")
        except StaleSpecError as e:

        except Exception as e:

    def _close(self) -> None:
        try:
            self.session.close()
        except (PendingEditsError, JobRunningError) as e:

    @ui.refreshable_method
    def _tests(self) -> None:
        project = self.session.project
        if project is None:
            return
        needle = {"text": ""}
        rows = ui.column().classes("w-full")

        def draw() -> None:

    def _select_one(self, model_id: str) -> None:

    def _toggle(self, model_id: str, on: bool) -> None:

    @ui.refreshable_method
    def _centre(self) -> None:
        project = self.session.project
        if project is None:

    def _tree_rows(self, model_id: str, node: dict, depth: int) -> None:
        indent = f"ml-{min(depth * 4, 16)}"
        if node.get("kind") == "leaf":
            verdict = "PASS" if node.get("passed") else "FAIL"
            text = (f"{node['path']}  {node.get('name') or node.get('variable')} · "

                tests={model_id}, variable=n.get("variable"), leaf_path=n["path"]
            )).props("flat dense no-caps align=left").classes(indent)
            if node.get("error"):
                ui.label(node["error"]).classes(f"{indent} text-negative text-xs")
            return
        label = node.get("combinator", "")

        ui.label(f"{node['path']}  {label}{extra} [{len(node.get('children') or [])}]").classes(indent)

    @ui.refreshable_method
    def _tabs(self) -> None:
        applicable = self.applicable()
        if not applicable:
            ui.label("nothing applies to this selection").classes("text-xs")
            return

            for cap, avail in applicable:
                tab = ui.tab(cap.label)
```

```python
"""Edit criteria (§4.6 table, §4.7): LEAF scope; a mode switch, the mode's
form, the window, the `against` selector. Each change stages one
`replace` of the leaf and the test rescores."""

from __future__ import annotations

from typing import Any

from ...comparison.mode_schema import derive_schema
from ...comparison.registry import metric, metrics
from ...comparison.tree_spec import LeafSpec, spec_to_raw
from ..capabilities import Panel, Patch, Scope
from ..session import SessionView
from ..spec_document import PatchOp

# NO module-level `nicegui` or `..forms` import: `import dstf.authoring` runs
# register_builtins(), and the Session must import without the extra.


def _leaf_node(view: dict | None, path: str) -> dict | None:
    if view is None:
        return None
    if view.get("path") == path:
        return view
    for child in view.get("children") or []:
        found = _leaf_node(child, path)
        if found is not None:
            return found
    return None


class EditCriteria:
    name = "edit-criteria"
    label = "Edit criteria"
    scope = Scope.LEAF

    def available(self, s: SessionView) -> bool | str:
        sel = s.selection
        (model_id,) = tuple(sel.tests) if len(sel.tests) == 1 else (None,)
        if model_id is None or sel.leaf_path is None:
            return "select one leaf"
        if s.is_locked(model_id):
            return f"{s.running.label} is running on {model_id}"
        return True

    def panel(self, s: SessionView, ui_panel: Panel) -> None:
        from nicegui import ui

        from ..forms import render_form

        sel = s.selection
        (model_id,) = tuple(sel.tests)
        leaf = _leaf_node(s.tree_view(model_id), sel.leaf_path or "")
        if leaf is None:
            ui.label("this leaf is not in the scored tree")
            return
        state: dict[str, Any] = {
            "metric": leaf["metric"], "variable": leaf["variable"], "params": dict(leaf.get("params") or {}),
            "against": leaf.get("against") or "primary",
            "window": dict(leaf.get("window") or {}),
        }
        ui.label(f"{leaf['variable']} · {sel.leaf_path}").classes("text-sm")
        if leaf.get("error"):
            ui.label(leaf["error"]).classes("text-negative")  # §4.7: inline on its form

        def emit() -> None:
            ui_panel.submit(model_id=model_id, path=sel.leaf_path, **state)

        form_slot = ui.column()

        def build_form() -> None:
            form_slot.clear()
            desc = metric(state["metric"])
            with form_slot:
                if desc is None:
                    ui.label(f"unknown metric {state['metric']!r}")
                    return
                render_form(derive_schema(desc.config_cls, mode=desc.name), state["params"],
                            on_change=lambda values: (state.update(params=values), emit()))

        def set_metric(name: str) -> None:
            state["metric"] = name
            state["params"] = {}   # a new mode starts from its defaults
            build_form()
            emit()

        ui.select([d.name for d in metrics()], label="mode", value=state["metric"],
                  on_change=lambda e: set_metric(e.value)).props("dense")
        build_form()
        with ui.row():
            ui.number(label="window start", value=state["window"].get("start"),
                      on_change=lambda e: (state["window"].update(start=e.value) if e.value is not None
                                           else state["window"].pop("start", None), emit())).props("dense")
            ui.number(label="window end", value=state["window"].get("end"),
                      on_change=lambda e: (state["window"].update(end=e.value) if e.value is not None
                                           else state["window"].pop("end", None), emit())).props("dense")
        names = list(s.project.baseline_names(model_id)) if s.project else ["primary"]
        ui.select(names or ["primary"], label="against", value=state["against"],
                  on_change=lambda e: (state.update(against=e.value), emit())).props("dense")

    def act(self, s: SessionView, **inputs: Any) -> Patch:
        leaf = LeafSpec(
            metric=inputs["metric"], variable=inputs["variable"], params=dict(inputs["params"]),
            against=inputs["against"], window_start=inputs["window"].get("start"),
            window_end=inputs["window"].get("end"),
        )
        return Patch(ops=[PatchOp(inputs["model_id"], "replace", inputs["path"], spec_to_raw(leaf))])
```
